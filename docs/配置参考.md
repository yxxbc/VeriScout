# VeriScout 配置参考

配置文件是 **JSON**，查找顺序（命中即止）：

1. `--config <path>` 显式指定
2. 环境变量 `$VES_CONFIG`
3. `./.ves/config.json`（当前工作目录）
4. `~/.ves/config.json`

没有配置文件时使用内置默认值。生成模板：`ves config init`；查看生效值：`ves config show`（密钥打码）。

---

## 1. 凭据解析顺序

命中即止：

1. 配置里的 `llm.api_key`（不推荐直接写明文）
2. 环境变量 `llm.api_key_env`（默认 `DEEPSEEK_API_KEY`）
3. 若 provider 是 `deepseek`，额外尝试 `$DEEPSEEK_API_KEY`
4. 依次扫描 `llm.credential_files` 里的 `KEY: value` / `KEY=value` 行

默认 `credential_files` 包含 `~/.dsh/.credentials.yaml` 与 `~/.ves/credentials.yaml`。
**因此在已配置 DSH 的机器上无需额外设置即可使用 DeepSeek。**

搜索类 Key（Tavily / Serper / Brave / 自定义端点）走同样的凭据扫描逻辑，只是返回空时对应引擎自动跳过。

## 2. 完整字段表

### 2.1 `llm`

| 字段 | 类型 | 默认 | 说明 |
| --- | --- | --- | --- |
| `provider` | string | `"deepseek"` | `deepseek` / `openai` / `ollama` / `custom`（仅作标记，实际用 `base_url`） |
| `base_url` | string | `"https://api.deepseek.com/v1"` | OpenAI 兼容端点；若已含 `/chat/completions` 则直接用 |
| `model` | string | `"deepseek-chat"` | 模型名 |
| `api_key_env` | string | `"DEEPSEEK_API_KEY"` | Key 所在环境变量名 |
| `api_key` | string | `""` | 内联 Key（优先级最高，注意不要提交到仓库） |
| `credential_files` | string[] | `["~/.dsh/.credentials.yaml","~/.ves/credentials.yaml"]` | 额外凭据文件 |
| `temperature` | number | `0.2` | 采样温度（研究任务建议低） |
| `max_tokens` | integer | `8192` | 单次回复上限 |
| `timeout_secs` | integer | `180` | 单次请求超时 |

### 2.2 `net`

搜索与抓取共用的网络行为。

| 字段 | 类型 | 默认 | 说明 |
| --- | --- | --- | --- |
| `retries` | integer | `3` | 额外重试次数。传输层失败（连接被重置、TLS 中断）对所有方法重试；429/5xx 只对 GET/HEAD 重试 |
| `backoff_ms` | u64 | `300` | 退避基数（毫秒），实际等待 = 基数 × 第几次尝试 |

> 本机网络对部分域名做**间歇性 TLS 重置**，同一个 URL 时通时断。默认 3 次重试 + 线性退避显著降低失败率；
> 若你的网络很稳定，可设为 `0` 让失败立刻暴露。

### 2.3 `search`

| 字段 | 类型 | 默认 | 说明 |
| --- | --- | --- | --- |
| `engines` | string[] | `["bing","wikipedia","duckduckgo","searx"]` | 通用引擎 |
| `vertical_engines` | string[] | `["googlenews","crossref","openalex","arxiv","hackernews","github","stackexchange"]` | 垂直引擎 |
| `searx_instances` | string[] | 5 个公共实例 | 按顺序轮换 |
| `results_per_engine` | integer | `8` | 每引擎取多少条 |
| `max_results` | integer | `30` | 合计上限 |
| `timeout_secs` | integer | `20` | 单引擎超时 |
| `user_agent` | string | 桌面 Chrome UA | —— |
| `tavily_api_key_env` / `serper_api_key_env` / `brave_api_key_env` | string | 对应 KEY 名 | 有 Key 才启用 |
| `custom_endpoint` | string | `""` | 自定义聚合端点（如 anysearch 桥）；非空才启用 `custom` 引擎 |
| `custom_api_key_env` | string | `"ANYSEARCH_API_KEY"` | 传给自定义端点的 Bearer Key（可选） |
| `anysearch_skill_dir` | string | `"~/.agents/skills/anysearch"` | 本地 AnySearch CLI 目录（内含 `scripts/anysearch_cli.{js,sh,py}`） |
| `anysearch_runtime` | string | `""` | 启动 CLI 的运行时：`node` / `bash` / `python3`；留空自动挑（优先 node，无第三方依赖） |
| `anysearch_timeout_secs` | integer | `45` | CLI 单次调用超时 |
| `anysearch_extract` | boolean | `true` | 允许 CLI 的 `extract` 渲染 JS 页面（deep 兜底 + `curl_tool render=true`） |
| `deep_fetch_pages` | integer | `0` | 默认 deep 抓取页数（工具参数可覆盖） |
| `max_body_bytes` | integer | `2000000` | 单页读取上限 |
| `blacklist` | object | 见 2.7 | 域名策略 |

### 2.4 `curl`

| 字段 | 类型 | 默认 | 说明 |
| --- | --- | --- | --- |
| `engine` | string | `"native"` | `native`（进程内，无子进程）或 `binary`（系统 curl，参数白名单） |
| `binary_path` | string | `"curl"` | `binary` 模式的可执行文件 |
| `timeout_secs` | integer | `30` | 默认超时 |
| `max_bytes` | integer | `400000` | 默认读取上限 |
| `follow_redirects` | boolean | `true` | 是否跟随重定向 |
| `max_redirects` | integer | `5` | 重定向上限 |
| `user_agent` | string | `"ves/0.1 …"` | 抓取 UA |
| `save_dir` | string | `"raw"` | `save=true` 的落盘目录（相对工作区） |
| `allow_private_addresses` | boolean | `false` | **建议保持 false**（关闭 SSRF 防护） |

### 2.5 `scripts`

| 字段 | 类型 | 默认 | 说明 |
| --- | --- | --- | --- |
| `python` | string | `"python3"` | 解释器路径 |
| `timeout_secs` | integer | `45` | 墙钟上限（同时作为沙箱 CPU 预算） |
| `cpu_seconds` | integer | `40` | CPU 时间 rlimit |
| `max_memory_mb` | integer | `512` | 地址空间 rlimit（macOS 上可能被忽略） |
| `max_output_bytes` | integer | `200000` | stdout/stderr 采集上限 |
| `allowed_modules` | string[] | 见下文 | 可导入模块白名单 |
| `allow_hosts` | string[] | `[]` | 非空时脚本只能访问这些域名 |
| `deny_hosts` | string[] | `["localhost","127.0.0.1"]` | 脚本禁止访问的域名 |
| `max_fetch_bytes` | integer | `1000000` | 脚本内 `fetch` 单次上限 |
| `network_enabled` | boolean | `true` | 直接切断脚本网络 |
| `keep_temp` | boolean | `false` | 保留沙箱临时目录（排障用） |

默认 `allowed_modules`：
`json re math statistics datetime time random string itertools functools collections typing dataclasses decimal fractions hashlib hmac base64 binascii textwrap unicodedata difflib html csv urllib.parse urllib.error urllib.request http.client email.utils uuid enum operator copy contextlib warnings`

> 注意 `os` `sys` `io` `subprocess` `socket` `pathlib` `shutil` `pickle` `ctypes` 一律不在白名单里。

### 2.6 `viz`

| 字段 | 类型 | 默认 | 说明 |
| --- | --- | --- | --- |
| `dir` | string | `"visualizations"` | 报告输出目录（相对工作区，或绝对路径） |
| `theme` | string | `"dark"` | `dark` / `light` |
| `keep_model` | boolean | `true` | 同时保存 `.json` 模型（`edit_html` 依赖它） |
| `open_after_create` | boolean | `false` | 生成后是否尝试打开 |
| `locale` | string | `"zh"` | 报告界面语言 |

### 2.7 `agent`

| 字段 | 类型 | 默认 | 说明 |
| --- | --- | --- | --- |
| `max_steps` | integer | `18` | 单次研究的最大模型轮次 |
| `max_tool_calls` | integer | `40` | 单次研究的工具调用上限 |
| `tool_output_chars` | integer | `12000` | 单条工具结果进入上下文前的截断长度 |
| `context_budget_chars` | integer | `220000` | 超过后压缩早期工具输出 |
| `system_prompt_extra` | string | `""` | 追加到系统提示词的额外要求 |
| `language` | string | `"zh"` | 输出语言偏好，写入系统提示词（`zh`→中文，`en`→English，其他值原样写入） |
| `style` | string | `"plain"` | 回答风格：`plain` 追加「说人话」要求（短句、术语先解释、结论先行）；其他值不加 |
| `trace` | boolean | `false` | 是否默认打印工具轨迹（CLI 的 `-q` 可覆盖） |

### 2.8 `search.blacklist`

| 字段 | 类型 | 默认 | 说明 |
| --- | --- | --- | --- |
| `blocked` | string[] | 约 30 条内容农场/广告域 | 支持 `example.com`、`*.sub.example.com`、`re:^ads?[0-9]*\.`（正则，忽略大小写） |
| `allowed` | string[] | `[]` | 白名单，优先于黑名单（用于放行被通配误伤的域名） |
| `block_private_addresses` | boolean | `true` | 私网/回环/link-local/CGNAT 拦截 + DNS 解析后校验 |

## 3. 示例配置

### 3.1 最小可用（免 Key 检索 + 本地模型）

```json
{
  "llm": { "provider": "ollama", "base_url": "http://localhost:11434/v1", "model": "qwen2.5:14b" },
  "viz": { "theme": "light" }
}
```

### 3.2 加装商业搜索

```json
{
  "search": {
    "engines": ["bing", "wikipedia", "tavily", "serper", "searx"],
    "tavily_api_key_env": "TAVILY_API_KEY",
    "serper_api_key_env": "SERPER_API_KEY"
  }
}
```

### 3.3 严格模式（只在白名单站点检索，脚本禁网）

```json
{
  "search": {
    "blacklist": {
      "blocked": ["re:.*"],
      "allowed": ["reuters.com", "apnews.com", "nature.com", "*.gov", "*.edu"],
      "block_private_addresses": true
    }
  },
  "scripts": { "network_enabled": false, "timeout_secs": 15 },
  "agent": { "max_steps": 10, "trace": true }
}
```

> `blocked: ["re:.*"]` 配 `allowed` 即「默认全禁，只放行白名单」。

### 3.4 本地 AnySearch CLI（默认启用）

```json
{
  "search": {
    "anysearch_skill_dir": "~/.agents/skills/anysearch",
    "anysearch_runtime": "node",
    "anysearch_timeout_secs": 45,
    "anysearch_extract": true,
    "engines": ["anysearch", "bing", "wikipedia", "duckduckgo", "searx"]
  },
  "net": { "retries": 3, "backoff_ms": 1000 }
}
```

未安装该 CLI 时引擎自动跳过（不报错、不影响其它引擎）。API Key 由 CLI 自行从技能目录的 `.env` 读取，
也可用环境变量 `ANYSEARCH_API_KEY`。若网络对 `api.anysearch.com` 抖动，请调大 `net.backoff_ms`
（CLI 路径每次重试至少等 1.5 秒）。

### 3.5 接入自定义聚合端点（HTTP 方式）

```json
{
  "search": {
    "custom_endpoint": "https://your-bridge.example/search",
    "custom_api_key_env": "ANYSEARCH_API_KEY",
    "engines": ["bing", "wikipedia", "custom"]
  }
}
```

端点需接受 `POST {"query": "...", "limit": N}`，返回数组或 `results/data/items` 数组，
元素含 `title/url/snippet` 之类字段即可（适配器会做字段名容错）。

## 5. 常见问题

**Q：报告写到哪里？**
`viz.dir` 相对当前工作目录（可用 `VES_WORKSPACE` 固定）。`ves viz path` 会打印绝对路径。

**Q：不想让 agent 落盘任何东西？**
`save` 是逐次调用参数，模型不用就不会写 `raw/`；`visualizations/` 是报告本身的落点，无法关闭（这是产品核心产出）。

**Q：脚本能读我的环境变量吗？**
不能。子进程用 `env_clear()` 启动，只设置 `PATH/HOME/TMPDIR/LANG/PYTHON*` 与沙箱配置路径。

**Q：搜索被墙了怎么办？**
`ves search … --json` 看 `engines[]` 里的 `error`；换网络、加商业搜索 Key，或改 `searx_instances` 用自建实例。
